# Brand style for documents

Change these values to give the documents your own look.
`style-application` reads this file.

## Colors
- Main color (name, headings): #ff6f3c (orange)
- Accent color (lines, small details): #ffb5b5 (soft orange)
- Text color: #393e46 (dark gray)
- Background: #FFFFFF (white)

## Fonts
- Headings: Georgia, serif
- Text: Arial, sans-serif
- Text size: 10.5–11 pt (never smaller than 10 pt)

## Layout
- One column, clean and calm
- Clear space between sections
- No photos, no icons, no emojis

## Margins and spacing
- Page margins: 2.5 cm on all sides (1 inch on Letter size, the US standard)
- Never smaller than 1.5 cm, so the page does not look crowded

**Resume**
- Line spacing: 1.3
- Space between sections: 14–16 pt
- Space between jobs in the same section: 8 pt
- Space between bullets: 4 pt

**Cover letter**
- Line spacing: 1.4
- Space between paragraphs: 12 pt
- Extra space before the greeting and before the signature: 18 pt

**Using the page well**
- If the document is shorter than one page, use the free space to add
  air: increase the spacing up to the values above, so the text is not
  squeezed at the top.
- If it is too long, reduce the spacing step by step, but never below a
  line spacing of 1.15, 10 pt between sections or 1.5 cm margins.
